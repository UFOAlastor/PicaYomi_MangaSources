# 拷贝源适配案例

适用源：**copymanga 1.5.0**；接口版本：**API v3**；最低插件版本：**0.10.8**。源代码位于 `sources/copymanga/`，在其他工作区中以 README 的 `PYSOURCE_ROOT` 设置为准。

本案例说明现有源如何把平台响应转换为 SDK 模型。路径、字段及认证方式随平台变化，维护时需重新核对实际响应。

## 能力与访问条件

源声明网站账号登录、推荐、最新、搜索、分类、排行、下载、本地收藏及网站账号收藏。匿名浏览和本地收藏可用；网站账号收藏要求登录，仍缺完整真实账号验证。

源未声明只读评论，也不提供发表评论或回复。新增能力应有可用接口、字段映射和错误处理依据，不能根据其他客户端的入口直接启用。

## 请求与字段映射

| 链路 | 源实现 | 校验重点 |
|---|---|---|
| 推荐 | 提取网站首页漫画推荐区的作品链接与封面 | 仅使用推荐区，单页；推荐与最新列表分开 |
| 最新 | newest 列表，offset=(page-1)*60、limit=60 | 提取稳定 path_word，解析分页 |
| 搜索 | 从搜索页读取站内 countApi 路径，再请求分页 JSON，limit=12 | 编码关键词，限制请求来源，验证 results.list |
| 分类 | /filter 提取主题；/comics 数据属性提供列表，limit=50 | 分类去重、排序、空结果、总量及字符串转义；不执行脚本 |
| 排行 | /rank?type=male/female&table=day/week/month/total | 八类榜单，限定作品区域，每榜单页 |
| 详情 | 页面标题、封面、作者、标签和简介 | 稳定作品身份及必需字段 |
| 章节 | 优先网站章节接口；登录时使用同源网站会话 | 完整分页，认证失败保留错误语义 |
| 匿名兼容路径 | 未登录且网站读取失败时，使用历史 App 分组与分页接口 | 校验 offset 和总量，不携带网站会话 |
| 图片 | 按稳定章节 ID 从对应接口取得完整列表 | 校验章节身份、数量及连续性 |

平台访问受限、认证失败与响应结构改变分别报错；两条读取路径均失败时保留失败结果，不返回伪造的空章节或图片列表。

## 列表展示与身份

源按卡片归属提取作者，分类保留多作者。网站状态映射为连载、完结或短篇；短篇不强行归入连载或完结。排行榜热度保存于 `metadata.heat`，不解释为已验证的阅读次数；推荐区缺少的字段不逐本补抓详情。

`list_display` 声明作者、状态、热度及更新时间等展示顺序。字段及限制见 [API v3 契约](CONTRACT.md#列表展示配置宿主-0108-起可选)。宿主支持的字段变化可由源独立更新。

作品身份使用 path_word，章节身份使用站内 UUID/id。API v3 返回规范的 Manga、Chapter、ListResult 和 PageList；宿主负责向阅读界面投影显示顺序与存储键。章节插入、重排或分组变化不能改变已有章节身份。

历史 App 分组优先 default，再按分组与站内顺序排序、去重。网页路径按分组和响应顺序映射；若发现两种路径身份不一致，先验证已有下载与续读的兼容性。

## 图片、地址与错误

- 网站、API 和图片服务分别处理；网站与 API 地址由源设置提供。
- 源按协议提供必要请求头；相对图片地址归一化后交给宿主下载。
- API v3 图片接口返回完整的 index/resource PageList，宿主统一调度、下载与解码。
- 加密响应校验 IV、密文格式、长度及解密后的 JSON。结构变化明确失败，诊断只保留必要的脱敏信息。
- 只请求预期的 HTTPS 来源及安全站内标识，不无限试探未知域名或接口。

## 登录与网站账号收藏

源使用网站账号密码登录和用户资料接口校验会话。token 由宿主加密保存并绑定网站 origin，不保存密码；更换网站地址后旧会话不可复用。会话只用于同源网站请求，不发送给图片 CDN 或历史 App 节点。

401 清除会话；其他平台错误按原始语义处理，不统一解释为账号不存在，也不自动反复重登。注册在平台官网完成。已登录时，章节和图片列表坚持网站链路，失败直接返回。

网站账号收藏的映射如下：

- 列表使用同源 `GET /api/v3/member/collect/comics`，每页 12 部、offset 分页，提供最近收藏或最近更新排序；条目读取嵌套 comic 的身份、标题及封面。
- 增删从详情页取得服务器 UUID，以 `POST /api/v2/web/collect` 设置 comic_id 与 is_collect；作品在收藏、下载和历史中的身份仍使用 path_word。
- 已登录详情从同源页面的书架按钮读取收藏状态；重复操作先检查当前状态，避免反向切换。错误响应不写入完整个人数据。

网站会话与 App 认证是不同链路。匿名阅读和离线会话测试不能作为真实账号登录、账号收藏或全站可用性的证明。

## 验证要求

离线断言应涵盖推荐区选择、列表分页、搜索字段、加解密向量、完整章节分页、图片完整性、稳定身份，以及 HTTP/结构错误。通用 fixture 检查器只覆盖输入样例声明的行为，还需源专属断言与宿主阅读链路验证。

真实接口验证分别记录匿名浏览、账号操作、章节与首图读取的日期、源版本和结果。账号、样本或设备不可用时明确记录未验证范围。完整清单见 [测试说明](TESTING.md)。
